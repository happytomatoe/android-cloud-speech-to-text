## Learnings

1. **Binding race condition**: `bindService()` is async. If `getValidApiKey()` is called before `onServiceConnected()`, it fails. Fixed with `getValidApiKeyWithRetry()` that waits up to 2000ms.

2. **`bindAttempted` flag must reset**: When `onServiceDisconnected()` fires, `bindAttempted` must be set to `false` to allow re-binding. Without this, the client can never reconnect after disconnection.

3. **Test file permissions**: Apps can't read from `/sdcard/` directly. Test files must be pushed to app's cache directory: `/sdcard/Android/data/com.example.whispertoinput/cache/`

4. **Release APK is unsigned**: The `assembleRelease` task produces an unsigned APK. Must sign with `apksigner` using a keystore. Keystore created at `/tmp/release-key.jks` with password `whisper123`.

5. **Android 11+ package visibility**: `<queries>` in manifest is required for `queryIntentServices()` to return results.
