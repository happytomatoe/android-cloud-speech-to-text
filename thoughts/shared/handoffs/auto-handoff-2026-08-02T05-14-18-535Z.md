## Learnings

### UI dump limitations:
- `uiautomator dump` only captures the **visible viewport** of a ScrollView — fields below the fold are silently omitted
- Use `dumpsys activity top` instead — it shows the **full view hierarchy** regardless of scroll position
- The previous session's "visibility bug" was a false alarm caused by uiautomator's viewport limitation

### Release APK constraints:
- Release APK is NOT debuggable — `run-as` fails with "package not debuggable"
- Must set credentials via UI automation (`input tap` + `input text`) or install debug APK first
- Debug keystore can sign release APK: `apksigner sign --ks ~/.android/debug.keystore --ks-pass pass:android`

### Samsung Galaxy A32 specifics (carried from previous handoff):
1. IME enable: `ime enable` fails. Use `settings put secure enabled_input_methods` with full list.
2. Storage: WAV must go to app-private storage via `run-as`. DataStore `test-file-path` needs absolute path.
3. DataStore refresh: Must `am force-stop` after writing DataStore via `run-as`.
4. IME must be set BEFORE showing keyboard.

### Mistral auth flow (from mistral-rotate-rest.ts):
- Login: POST `https://auth.mistral.ai/self-service/login?flow=<flowId>` with email/password/CSRF
- Handle 410 error → get new flowId → retry
- Create key: POST `https://console.mistral.ai/api/billing/api-keys` with session cookies
- Default flowId: `430d8f95-96ab-4d6e-9090-ed521c8932c2`
- Workspace UUID: `7960afd8-0194-4178-8a8f-52f550ec6c44`
