## Learnings

1. **AIDL requires explicit enablement**: The `build.gradle.kts` needs `aidl = true` in `buildFeatures` block — without it, the AIDL file is silently ignored and imports fail at compile time.
2. **X11 authorization is the emulator killer**: This host environment cannot start the Android emulator due to missing X11 authorization (`Authorization required, but no authorization protocol specified`). Neither headful nor headless modes work. The `QT_QPA_PLATFORM=offscreen` trick doesn't help because the emulator's internal rendering still needs X11.
3. **Emulator starts then segfaults**: When using `-gpu swiftshader_indirect`, the emulator gets further (boots Android, sends ADB public key) but then segfaults. This may be related to the same X11 issue.
4. **`kill -9` is forbidden in this sandbox**: The pi-agent sandbox blocks `kill` commands to arbitrary PIDs. You cannot kill stuck processes.
5. **Credentials are in Linux keyring**: Mistral email/password stored via `secret-tool` (service=mistral). The key-manager Android app needs these to rotate API keys via Mistral's auth API.
