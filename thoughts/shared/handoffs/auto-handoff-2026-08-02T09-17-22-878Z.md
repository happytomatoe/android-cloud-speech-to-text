## Learnings

1. **Android 11+ package visibility**: Must use `<queries>` with intent action to discover services. Without it, `queryIntentServices()` returns empty.

2. **Service discovery requires intent-filter**: Key-manager apps must declare service with action `com.example.keymanager.MISTRAL_KEY_SERVICE` in their manifest to be discoverable.

3. **Cannot use random apps as key-managers**: Only apps exposing the exact same AIDL interface (`IMistralKeyManager`) will work. The `<queries>` intent filter discovers these apps.

4. **Broadcast toggle needs `toggleRecording()`**: Original `tryStartRecording()` only works when idle. Added `toggleRecording()` to handle both Idle→Recording and Recording→Transcribing.

5. **Samsung IME override**: Default IME reverts to Samsung keyboard. Must explicitly set whisper as default via `adb shell ime set`.
