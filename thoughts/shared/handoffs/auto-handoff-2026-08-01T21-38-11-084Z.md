## Learnings

### Samsung Galaxy A32 5G specifics:
1. **IME enable**: `ime enable` fails on Samsung. Use `settings put secure enabled_input_methods` with full list.
2. **Storage permissions**: App doesn't request `READ_EXTERNAL_STORAGE`. WAV must go to app-private storage via `run-as`. DataStore `test-file-path` needs absolute path: `/data/user/0/com.example.whispertoinput/files/test-speech-loud.wav`
3. **DataStore refresh**: Must `am force-stop` after writing DataStore via `run-as`.
4. **IME must be set BEFORE showing keyboard**: Otherwise Samsung IME intercepts and broadcast doesn't reach our service.
5. **Broadcast detection**: Test file mode only logs `onReceive: action=...`, not "Recording started".
6. **Deepgram key expired**: `f97f6e1e42b697792bfe1867f7679fdeaace4de8` → `INVALID_AUTH`. New working key: `11f60d2a5f21c0a181961250804ba123e3261107`

### Mistral auth flow (from mistral-rotate-rest.ts):
- Login: POST `https://auth.mistral.ai/self-service/login?flow=<flowId>` with email/password/CSRF
- Handle 410 error → get new flowId → retry
- Create key: POST `https://console.mistral.ai/api/billing/api-keys` with session cookies
- Credentials stored in Linux keyring via `secret-tool`: `secret-tool lookup service mistral type email`
- Default flowId: `430d8f95-96ab-4d6e-9090-ed521c8932c2`
- Workspace UUID: `7960afd8-0194-4178-8a8f-52f550ec6c44`
