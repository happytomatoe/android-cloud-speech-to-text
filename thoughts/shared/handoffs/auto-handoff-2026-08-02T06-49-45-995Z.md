## Learnings

### WhisperKeyboard architecture:
- `WhisperKeyboard` manages its own state machine (Idle → Recording → Transcribing)
- It handles all UI updates internally (button visibility, status text, mic icon)
- The service only needs to provide callbacks for business logic
- `tryStartRecording()` and `tryStartTranscribing()` are no-ops if state doesn't match

### Mistral Auth API flow (from patch):
1. GET `https://auth.mistral.ai/self-service/login/api` → fresh flow ID
2. POST `https://auth.mistral.ai/self-service/login?flow={flowId}` → session token
3. POST `https://console.mistral.ai/api/billing/api-keys` with Bearer token → API key
4. **Critical:** Must NOT send `Origin` header on login request (CSRF block)

### Key rotation architecture options discussed:
1. **Separate Android Service** — Periodic key validation in background
2. **Server-Side Key Manager** — Centralized rotation via Cloudflare Worker or similar
3. **Local Key Validator (Recommended)** — Standalone `MistralKeyValidator` class:
   - Validates current key with lightweight API call
   - Rotates if invalid using saved credentials
   - IME calls before transcription, caches result
4. **Key Rotation on App Start** — Always refresh on launch
