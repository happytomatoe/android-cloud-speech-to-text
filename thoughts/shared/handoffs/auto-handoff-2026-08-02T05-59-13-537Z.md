## Learnings

### Mistral Auth API flow:
1. GET `https://auth.mistral.ai/self-service/login/api` → returns fresh `id` (flow ID)
2. POST `https://auth.mistral.ai/self-service/login?flow={flowId}` with email/password → returns `session_token`
3. POST `https://console.mistral.ai/api/billing/api-keys` with `Authorization: Bearer {session_token}` → returns API key

**Critical:** The `Origin` header must NOT be sent on the login request when flow was initiated as API request. Mistral blocks it as CSRF protection.

### IME architecture:
- `WhisperKeyboard.kt` is a **complete, reusable keyboard component** with full button handling
- `WhisperInputService.kt` is a **separate, simpler implementation** that does NOT use `WhisperKeyboard`
- The buttons exist in the XML layout but `WhisperInputService` only wires up the mic button
- Fix: Refactor `WhisperInputService` to use `WhisperKeyboard.setup()` which wires all buttons

### Samsung keyboard quirks (from previous session):
- `input text` mangles `.` (period) and `@` (at) characters
- `KEYCODE_CTRL_A` for select-all triggers spinner dropdown instead
- Triple-tap + cut (keyevent 277) works for selecting all text
- `KEYCODE_BACK` (4) closes the app if keyboard is already dismissed
